# Анализ недавней работы агентов

По умолчанию этот сценарий **приостановлен** и не расходует токены, пока оператор не включит расписание или не запустит его вручную. При запуске он создаёт только предложения по улучшению.

## Что должен сделать этот запуск

1. Выберите целевых агентов согласно `{{targetAgentMode}}`:
   - `recent_active` — агенты с завершёнными, проверяемыми или заблокированными задачами за последние `{{lookbackDays}}` дней;
   - `all` — все незавершённые агенты компании;
   - `explicit` — только агенты, явно указанные во входных данных запуска.
   Ограничьте выбор значением `{{maxTargetAgents}}`. Исключите идентификаторы из `{{excludeAgentIds}}` и всегда исключайте собственный `PAPERCLIP_AGENT_ID`: анализировать себя запрещено.
2. Для каждого выбранного агента следуйте навыку `reflection-coach`: соберите недавнюю историю работы, прочитайте текущий AGENTS.md и назначенные навыки, объедините подтверждённые фактами закономерности и подготовьте минимальное устойчивое изменение.
3. Для каждого агента создайте документ предложения: группы закономерностей, ссылки на подтверждающие задачи и комментарии, минимальные изменения и примеры повторной проверки. Если изменение стоит продолжения, создайте отдельную задачу предложения.

## Жёсткие ограничения сценария

- Только предложения. Сценарий не должен напрямую изменять действующий AGENTS.md агента, назначения навыков или описания инструментов.
- Любое изменение инструкции, навыка или описания инструмента требует показанной разницы и **принятого** взаимодействия `request_confirmation`; применять его можно только в отдельном последующем запуске.
- Подтверждения изменений должны быть привязаны к точному ключу ресурса: `agent:<agentId>:instructions`, `agent:<agentId>:profile`, `skill:<skillId>`, `skill-slug:<slug>`, `skill-import:<source>` или `skills:scan-projects`.
- Все чтения должны оставаться в пределах компании. Не пересекайте границы компаний.
- Каждое предлагаемое правило должно иметь ссылку на подтверждающую задачу или комментарий, иначе его нужно исключить. Не оценивайте агентов без истории работы.
- Соблюдайте ограничения размера: рост AGENTS.md не более 20% за предложение, навыки не более 15 КБ, описания инструментов не более 500 символов.

## Результат

Одна ограниченная задача сценария со ссылкой на документ предложения или последующую задачу для каждого проверенного агента, а также итоговый комментарий: какие агенты проверены, какой период рассмотрен, какие группы закономерностей найдены, какие поверхности предложено изменить и кто отвечает за следующий шаг по каждому принятому или ожидающему решению изменению.
